# QuizMaster – Online Quiz System

QuizMaster is a web-based online quiz application that allows users to participate in quizzes, test their knowledge, view scores, and track their performance.

## Features

### User Module
- User Registration and Login
- Profile Management
- Browse Quiz Categories
- Attend Quizzes
- Submit Answers and View Scores
- Quiz History
- Global Leaderboard

### Admin Module
- Admin Login
- Add, Update and Delete Quiz Categories
- Add, Update and Delete Questions
- View Registered Users
- View Quiz Results

## Technologies Used

**Frontend:** HTML, CSS, JavaScript

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Tools:** VS Code, Git, GitHub

## Project Structure

- Frontend pages and scripts
- Backend API routes
- MongoDB models
- User and Admin modules

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/hasanathph/QuizMaster.git
   ```

2. Navigate to the backend folder:

   ```bash
   cd QuizMaster/backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file and configure your MongoDB connection and admin credentials.

5. Start the backend server:

   ```bash
   node server.js
   ```

6. Open `index.html` using Live Server.
